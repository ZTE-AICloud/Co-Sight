# 品牌标识

| 文件 | 用途 |
| --- | --- |
| `zte-logo.svg` | ZTE 标准 LOGO，蓝色、透明底；浅色背景 |
| `zte-logo-white.svg` | ZTE 标准 LOGO，白色、透明底；深色背景 |
| `zte-mark.svg` | 方形蓝底反白版；favicon 与 `src/shared/ui/BrandMark.vue` |
| `zte-mark-512.png` | 同上的 512×512 PNG；用于 GitHub 组织头像上传（GitHub 不支持 SVG 头像） |

来源：公司品牌部 `ZTElogo（多格式）.7z` 中的 `ZTE LOGO.ai`（标准 LOGO 矢量文件）。
官方色值以 `ZTE LOGO_含色值.ai` 为准：CMYK 100/25/0/0、PANTONE Process Blue C/U、
RGB 0/142/211、HTML `#0099CC`。

使用时保持原始比例与留白，不要拉伸、改色或加效果。
