## [0.2.0] - 2026-11-09

首个开源版本。

### 功能

- 文档知识库：目录树、批量导入、解析/切片、切片查看与手工新增、状态与统计。
- 图谱知识库：Schema 定义或通用抽取、实体/关系编辑、图谱查询与图谱检索。
- 检索编排：画布编排、发布为快照、按 DAG 执行，支持 Sequential / Blended / Conditional。
- 问答：SSE 流式返回，逐条给出知识库依据与分阶段耗时。
- 模型管理：OpenAI 兼容的 embedding / 生成 / 重排端点注册、连接测试与凭据加密。
- Agent 接口：REST + MCP，支持检索、问答与已发布工作流执行。
- 本地账号登录、API Key 管理、审计与查询轨迹。
- 中 / 英双语界面，深色 / 浅色主题。
