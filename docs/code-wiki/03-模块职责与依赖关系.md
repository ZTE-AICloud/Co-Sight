# 03 模块职责与依赖关系

## 主要模块职责

### 1) `app/cosight`：Agent 执行引擎

- `agent/`
  - `base/`：通用 Agent 基类、工具 schema 生成、工具参数映射、MCP 工具桥接（见 [base_agent.py](file:///d:/lingdong/Co-Sight/app/cosight/agent/base/base_agent.py)，[skill_to_tool.py](file:///d:/lingdong/Co-Sight/app/cosight/agent/base/skill_to_tool.py)）。
  - `planner/`：计划生成（create/replan/finalize）与 prompt（见 [task_plannr_agent.py](file:///d:/lingdong/Co-Sight/app/cosight/agent/planner/task_plannr_agent.py)）。
  - `actor/`：步骤执行与工具注入（见 [task_actor_agent.py](file:///d:/lingdong/Co-Sight/app/cosight/agent/actor/task_actor_agent.py)）。
- `task/`
  - `Plan`（DAG）：步骤/依赖/状态/工具调用记录/产物文件追踪（见 [todolist.py](file:///d:/lingdong/Co-Sight/app/cosight/task/todolist.py)）。
  - `TaskManager`：plan_id ⇄ Plan 的全局注册表 + 运行中幂等标记（见 [task_manager.py](file:///d:/lingdong/Co-Sight/app/cosight/task/task_manager.py)）。
  - `plan_report_manager`：轻量事件总线（按 event_type + plan_id 订阅/发布）（见 [plan_report_manager.py](file:///d:/lingdong/Co-Sight/app/cosight/task/plan_report_manager.py)）。
- `llm/`：OpenAI 兼容的 Chat 客户端封装（工具调用、上下文截断/压缩、Langfuse tracing）（见 [chat_llm.py](file:///d:/lingdong/Co-Sight/app/cosight/llm/chat_llm.py)）。
- `tool/`：工具集合（文件、搜索、网页抓取、代码执行、文档处理、多模态、HTML 报告等）（见 [tool](file:///d:/lingdong/Co-Sight/app/cosight/tool)）。

### 2) `cosight_server`：Web 服务与前端

- `deep_research/main.py`：FastAPI 应用装配、目录挂载、路由注册、uvicorn 启动（见 [main.py](file:///d:/lingdong/Co-Sight/cosight_server/deep_research/main.py)）。
- `deep_research/routers/`：API 与 WebSocket
  - `search.py`：核心“深度研究”接口，负责启动 CoSight、订阅事件、流式输出（见 [search.py](file:///d:/lingdong/Co-Sight/cosight_server/deep_research/routers/search.py)）。
  - `websocket_manager.py`：WebSocket 接入层，将前端消息转发到 `search` 并将流式结果再推回（见 [websocket_manager.py](file:///d:/lingdong/Co-Sight/cosight_server/deep_research/routers/websocket_manager.py)）。
  - `user_manager.py`：登录/登出（见 [user_manager.py](file:///d:/lingdong/Co-Sight/cosight_server/deep_research/routers/user_manager.py)）。
  - `common.py`：服务器时间戳、停止消息（见 [common.py](file:///d:/lingdong/Co-Sight/cosight_server/deep_research/routers/common.py)）。
  - `chat_manager.py`：会话列表/创建/编辑（示例化实现）（见 [chat_manager.py](file:///d:/lingdong/Co-Sight/cosight_server/deep_research/routers/chat_manager.py)）。
  - `feedback.py`：反馈原因（占位返回）（见 [feedback.py](file:///d:/lingdong/Co-Sight/cosight_server/deep_research/routers/feedback.py)）。
- `sdk/`：配置、缓存、会话管理、工具函数等（见 [sdk](file:///d:/lingdong/Co-Sight/cosight_server/sdk)）。
- `web/`：前端静态资源（见 [cosight_server/web](file:///d:/lingdong/Co-Sight/cosight_server/web)）。

### 3) `app/agent_dispatcher`：技能与 MCP 适配层

- `domain/plan/action/skill/mcp/`：MCP Server（stdio/sse）封装与工具调用（见 [engine.py](file:///d:/lingdong/Co-Sight/app/agent_dispatcher/domain/plan/action/skill/mcp/engine.py)，[server.py](file:///d:/lingdong/Co-Sight/app/agent_dispatcher/domain/plan/action/skill/mcp/server.py)）。
- `infrastructure/entity/`：Agent/Skill/Message 等实体定义（见 [infrastructure/entity](file:///d:/lingdong/Co-Sight/app/agent_dispatcher/infrastructure/entity)）。

## 依赖关系（模块级）

一个简化的依赖图（箭头表示“依赖于”）：

- `cosight_server/deep_research/*` → `CoSight.py` → `app/cosight/*`
- `app/cosight/agent/*` → `app/cosight/llm/*`、`app/cosight/tool/*`、`app/cosight/task/*`
- `app/cosight/agent/base/*` → `app/agent_dispatcher/*`（技能/MCP 工具 schema 与调用）
- `llm.py` → `config/config.py` → `.env`（环境变量）

## 关键三方依赖（按能力归类）

依赖列表见 [requirements.txt](file:///d:/lingdong/Co-Sight/requirements.txt)。

- Web 与通信：`fastapi`、`uvicorn`（间接）、`websockets`、`aiohttp`
- OpenAI 兼容模型调用：`openai`、`httpx`
- 工具与 Agent 框架：`lagent`、`mcp`
- 可观测性：`langfuse`
- 搜索与抓取：`tavily-python`、`googlesearch-python`、`wikipedia`、`markdownify`
- 文档/多媒体处理：`pdfplumber`、`PyMuPDF`、`ffmpeg-python`、`soundfile`
- 可视化/报告：`markdown`、`plotly`、`kaleido`、`seaborn`
