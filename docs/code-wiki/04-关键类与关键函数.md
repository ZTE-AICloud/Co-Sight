# 04 关键类与关键函数

本页只覆盖“理解系统运行必须掌握”的对象；工具类（FileToolkit、SearchToolkit…）建议按需阅读 `app/cosight/tool/`。

## CoSight（顶层引擎）

- 定义位置：[CoSight.py](file:///d:/lingdong/Co-Sight/CoSight.py)
- 核心职责
  - 创建并注册 `Plan` 到 `TaskManager`
  - 将多个 LLM 实例绑定到同一 `plan_id`（Langfuse session 维度）
  - 规划 → 并发执行步骤 → 最终汇总
- 关键方法
  - `__init__`：生成 `plan_id`，初始化 Planner Agent（见 [CoSight.py:L34-L75](file:///d:/lingdong/Co-Sight/CoSight.py#L34-L75)）
  - `execute(question, output_format="")`：循环取 ready steps 并启动线程执行（见 [CoSight.py:L76-L132](file:///d:/lingdong/Co-Sight/CoSight.py#L76-L132)）
  - `_execute_single_step(question, step_index)`：每个步骤独立创建 Actor 实例，避免线程间共享状态（见 [CoSight.py:L133-L150](file:///d:/lingdong/Co-Sight/CoSight.py#L133-L150)）

## Plan（DAG 计划对象）

- 定义位置：[todolist.py](file:///d:/lingdong/Co-Sight/app/cosight/task/todolist.py)
- 关键字段
  - `steps: list[str]`：步骤列表（注意：以“步骤文本”作为状态字典 key）
  - `dependencies: dict[int, list[int]]`：邻接表依赖（步骤索引）
  - `step_statuses/step_notes/step_details/step_files`：步骤状态与产物追踪
  - `step_tool_calls`：步骤内工具调用轨迹（也支持 `step_index=-1` 的“全局/MCP 工具”）
- 关键方法
  - `get_ready_steps()`：依赖都满足且未开始的步骤索引（见 [todolist.py:L57-L75](file:///d:/lingdong/Co-Sight/app/cosight/task/todolist.py#L57-L75)）
  - `update(...)`：更新计划时保留已开始/已完成步骤的状态（见 [todolist.py:L77-L130](file:///d:/lingdong/Co-Sight/app/cosight/task/todolist.py#L77-L130)）
  - `mark_step(step_index, ...)`：状态流转 + 产物路径清洗（见 [todolist.py:L131-L161](file:///d:/lingdong/Co-Sight/app/cosight/task/todolist.py#L131-L161)）
  - `add_tool_call(step_index, ...)`：记录工具调用信息（见 [todolist.py:L162-L204](file:///d:/lingdong/Co-Sight/app/cosight/task/todolist.py#L162-L204)）

## BaseAgent（LLM 工具调用循环）

- 定义位置：[base_agent.py](file:///d:/lingdong/Co-Sight/app/cosight/agent/base/base_agent.py)
- 核心职责
  - 将 skill/MCP 配置转换为 OpenAI tool schema（工具元信息）
  - 执行“LLM → tool_calls → tool results → 再喂回 LLM”的循环
  - 统一上报工具事件（tool_start/tool_complete/tool_error）
- 关键方法
  - `execute(messages, step_index=None, max_iteration=10)`：一次步骤内的最多 N 轮工具调用迭代（见 [base_agent.py:L384-L486](file:///d:/lingdong/Co-Sight/app/cosight/agent/base/base_agent.py#L384-L486)）
  - `_execute_tool_calls(...)`：并行执行所有 tool_calls（线程池）（见 [base_agent.py:L439-L474](file:///d:/lingdong/Co-Sight/app/cosight/agent/base/base_agent.py#L439-L474)）
  - `_push_tool_event(...)`：发布工具事件到 `plan_report_event_manager`（见 [base_agent.py:L155-L214](file:///d:/lingdong/Co-Sight/app/cosight/agent/base/base_agent.py#L155-L214)）

## TaskPlannerAgent（规划 Agent）

- 定义位置：[task_plannr_agent.py](file:///d:/lingdong/Co-Sight/app/cosight/agent/planner/task_plannr_agent.py)
- 注入工具（对 LLM 暴露）
  - `create_plan / update_plan`：来自 `PlanToolkit`
  - `terminate`：终止执行
- 关键方法
  - `create_plan(...)`：一次性生成计划（只迭代 1 次）并落地到 `Plan`（见 [task_plannr_agent.py:L40-L44](file:///d:/lingdong/Co-Sight/app/cosight/agent/planner/task_plannr_agent.py#L40-L44)）
  - `finalize_plan(...)`：根据 Plan 状态生成最终总结，并发布 `plan_result`（见 [task_plannr_agent.py:L52-L67](file:///d:/lingdong/Co-Sight/app/cosight/agent/planner/task_plannr_agent.py#L52-L67)）

## TaskActorAgent（执行 Agent）

- 定义位置：[task_actor_agent.py](file:///d:/lingdong/Co-Sight/app/cosight/agent/actor/task_actor_agent.py)
- 核心职责
  - 为某个 step_index 构建执行 prompt，并调用 `BaseAgent.execute()`
  - 注入一组工具函数（文件、搜索、抓取、代码执行、多模态、报告生成…）
- 关键方法
  - `__init__(...)`：从 `TaskManager` 取回 Plan；构造各类 Toolkit 并注入 `functions`（见 [task_actor_agent.py:L46-L132](file:///d:/lingdong/Co-Sight/app/cosight/agent/actor/task_actor_agent.py#L46-L132)）
  - `act(question, step_index)`：标记状态、发布计划进度、执行并在成功/失败时更新 Plan（见 [task_actor_agent.py:L141-L172](file:///d:/lingdong/Co-Sight/app/cosight/agent/actor/task_actor_agent.py#L141-L172)）

## ChatLLM（OpenAI 兼容客户端封装）

- 定义位置：[chat_llm.py](file:///d:/lingdong/Co-Sight/app/cosight/llm/chat_llm.py)
- 关键点

- `TaskManager`：存放运行中 Plan、做 plan_id 映射与幂等（见 [task_manager.py](file:///d:/lingdong/Co-Sight/app/cosight/task/task_manager.py)）。
- `plan_report_event_manager`：按 plan_id 隔离的事件订阅/发布（见 [plan_report_manager.py](file:///d:/lingdong/Co-Sight/app/cosight/task/plan_report_manager.py)）。
