# 06 配置与运行方式

## Python 与依赖安装

- Python 版本：`>= 3.11`（见 [README.md](file:///d:/lingdong/Co-Sight/README.md#L44-L49)）
- 安装依赖（仓库根目录）：

```bash
pip install -r requirements.txt
```

依赖文件见 [requirements.txt](file:///d:/lingdong/Co-Sight/requirements.txt)。

## `.env` 环境变量（核心）

项目通过环境变量驱动模型/搜索/上下文管理等配置，模板见 [.env_template](file:///d:/lingdong/Co-Sight/.env_template)。

必须配置（最小可运行集合）：

- `API_KEY`：OpenAI 兼容接口密钥
- `API_BASE_URL`：OpenAI 兼容接口 base_url
- `MODEL_NAME`：默认模型名

可选但常用：

- `TURBO_MODE`：急速模式（减少迭代/文件生成，见 [BaseAgent.execute](file:///d:/lingdong/Co-Sight/app/cosight/agent/base/base_agent.py#L384-L410)）
- `ENABLE_CONTEXT_COMPRESSION` 等：上下文压缩（见 [.env_template:L9-L23](file:///d:/lingdong/Co-Sight/.env_template#L9-L23) 与 [chat_llm.py:L784-L799](file:///d:/lingdong/Co-Sight/app/cosight/llm/chat_llm.py#L784-L799)）
- 搜索能力：`TAVILY_API_KEY`、`GOOGLE_API_KEY`、`SEARCH_ENGINE_ID`（见 [.env_template:L55-L62](file:///d:/lingdong/Co-Sight/.env_template#L55-L62)）
- Langfuse：`LANGFUSE_ENABLED`、`LANGFUSE_SECRET_KEY`、`LANGFUSE_PUBLIC_KEY`（见 [.env_template:L29-L35](file:///d:/lingdong/Co-Sight/.env_template#L29-L35)）
- 模型分层：`PLAN_* / ACT_* / TOOL_* / VISION_* / CREDIBILITY_* / BROWSER_*`（见 [.env_template:L84-L134](file:///d:/lingdong/Co-Sight/.env_template#L84-L134)，读取逻辑见 [config.py](file:///d:/lingdong/Co-Sight/config/config.py)）

- `llm_for_plan/act/tool/vision/credibility`：模块级单例（见 [llm.py:L83-L101](file:///d:/lingdong/Co-Sight/llm.py#L83-L101)）

## 运行方式 A：启动 Web 服务（推荐）

1. 复制环境变量模板：

```bash
copy .env_template .env
```

2. 编辑 `.env` 写入最少的模型配置（`API_KEY/API_BASE_URL/MODEL_NAME`）。
3. 启动 FastAPI（直接运行入口脚本即可）：

```bash
python cosight_server/deep_research/main.py
```

4. 浏览器打开：

- `http://localhost:7788/cosight/`（见 [README.md](file:///d:/lingdong/Co-Sight/README.md#L82-L88)）

## 工作区与产物目录

- Web 服务启动时会确保存在 `work_space/` 并设置 `WORKSPACE_PATH`（见 [main.py:L119-L129](file:///d:/lingdong/Co-Sight/cosight_server/deep_research/main.py#L119-L129)）。
- 每次任务（非回放）会创建 `work_space/work_space_时间戳/`，并把 `WORKSPACE_PATH` 更新为该目录（见 [search.py:L421-L430](file:///d:/lingdong/Co-Sight/cosight_server/deep_research/routers/search.py#L421-L430)）。
- `work_space/plans/`：按 plan_id 记录日志与 final（见 [search.py:L414-L417](file:///d:/lingdong/Co-Sight/cosight_server/deep_research/routers/search.py#L414-L417)）。
