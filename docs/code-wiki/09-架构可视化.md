## 请求时序图（WebSocket → Streaming → 计划执行）

```mermaid
sequenceDiagram
  autonumber
  participant B as Browser UI
  participant W as WebSocket Router<br/>websocket_manager.py
  participant S as Search API<br/>search.py
  participant C as CoSight<br/>CoSight.py
  participant P as TaskPlannerAgent
  participant A as TaskActorAgent
  participant T as Tools

  B->>W: action=message(topic, initData)
  W->>S: POST /deep-research/search (stream=true)
  S->>C: CoSight.execute(question)
  C->>P: create_plan()
  loop until Plan finished
    C->>C: Plan.get_ready_steps()
    par for each ready step
      C->>A: act(question, step_index)
      loop tool-calling loop
        A->>T: run tool(s)
        T-->>A: tool result(s)
      end
      A-->>S: publish plan/tool events
    end
  end
  C-->>S: finalize_plan()
  S-->>W: StreamingResponse chunks
  W-->>B: push updates to topic
```

## 关键类图（Core Classes）

```mermaid
classDiagram
  class CoSight {
    +work_space_path: str
    +plan_id: str
    +plan: Plan
    +task_planner_agent: TaskPlannerAgent
    +execute(question, output_format) str
  }

  class Plan {
    +title: str
    +steps: list~str~
    +dependencies: dict~int, list~int~~
    +step_statuses: dict~str,str~
    +get_ready_steps() list~int~
    +mark_step(step_index, step_status, step_notes)
    +add_tool_call(step_index, tool_name, tool_args, tool_result)
  }

  class BaseAgent {
    +agent_instance
    +llm: ChatLLM
    +tools: list
    +functions: dict
    +execute(messages, step_index, max_iteration)
  }

  class TaskPlannerAgent {
    +create_plan(question, output_format)
    +re_plan(question, output_format)
    +finalize_plan(question, output_format)
  }

  class TaskActorAgent {
    +act(question, step_index)
  }

  class ChatLLM {
    +model: str
    +create_with_tools(messages, tools)
    +chat_to_llm(messages, max_tokens)
  }

  class TaskManager {
    <<static>>
    +plans: dict
    +set_plan(plan_id, plan)
    +get_plan(plan_id) Plan
  }

  CoSight --> Plan
  CoSight --> TaskPlannerAgent
  CoSight ..> TaskActorAgent : create per step/thread
  TaskPlannerAgent --|> BaseAgent
  TaskActorAgent --|> BaseAgent
  BaseAgent --> ChatLLM
  TaskManager ..> Plan
  TaskPlannerAgent ..> Plan : writes/updates
  TaskActorAgent ..> Plan : marks step/status/toolcalls
```
