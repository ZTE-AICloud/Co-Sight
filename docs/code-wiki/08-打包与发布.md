# 08 打包与发布

## 打包脚本入口

- 位置：[tools/build.py](file:///d:/lingdong/Co-Sight/tools/build.py)
- 目标：使用 PyInstaller 将 Web 服务入口 `cosight_server/deep_research/main.py` 打包成可分发的可执行目录（`dist/Cosight`）。

## 打包时包含的关键资源

脚本会把静态前端与部分配置/i18n 资源作为 data files 打包进去（见 [build.py:L94-L99](file:///d:/lingdong/Co-Sight/tools/build.py#L94-L99)）：

- `cosight_server/web`（前端）
- `cosight_server/deep_research/services/i18n.json`
- `app/cosight/tool/deep_search/common/i18n.json`
- `config/`（包含 `mcp_server_config.json` 等）

## spec 生成与执行

- 脚本会动态生成 `tools/Cosight.spec`，其中：
  - `Analysis([main.py])`：入口脚本为 `cosight_server/deep_research/main.py`（见 [build.py:L102-L107](file:///d:/lingdong/Co-Sight/tools/build.py#L102-L107)）
  - `hiddenimports`：显式声明一些运行时依赖（browser_use、qdrant_client 等）（见 [build.py:L150-L169](file:///d:/lingdong/Co-Sight/tools/build.py#L150-L169)）
  - 自动扫描 `app/` 下所有可导入模块加入 hiddenimports（见 [build.py:L171-L177](file:///d:/lingdong/Co-Sight/tools/build.py#L171-L177)）
- 执行打包：`pyinstaller --clean tools/Cosight.spec`（见 [build.py:L223-L225](file:///d:/lingdong/Co-Sight/tools/build.py#L223-L225)）

## 环境配置文件处理

- 如果存在 `.env`，脚本会生成一个“脱敏后的示例 .env”并拷贝到输出目录，避免把密钥随产物分发（见 [build.py:L245-L259](file:///d:/lingdong/Co-Sight/tools/build.py#L245-L259)）。
