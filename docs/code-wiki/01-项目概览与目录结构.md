# 01 项目概览与目录结构

## 项目定位

Co-Sight 是一个“Planner + Actor + Tool Calling”的任务型 Agent 系统，支持通过 Web（FastAPI + WebSocket）提供交互式“深度研究”体验：用户输入任务 → 生成计划（DAG）→ 多线程并发执行步骤 → 流式推送过程与报告。

## 仓库顶层结构

以下结构以仓库根目录为基准（`d:\lingdong\Co-Sight`）：

- `CoSight.py`：核心引擎，负责创建 Plan、调度步骤并发执行、最终汇总（见 [CoSight.py](file:///d:/lingdong/Co-Sight/CoSight.py)）。
- `llm.py`：将环境变量配置装配为多个用途的 LLM 实例（plan/act/tool/vision/credibility）（见 [llm.py](file:///d:/lingdong/Co-Sight/llm.py)）。
- `config/`：读取 `.env`、提供模型/工具相关配置函数、MCP 配置文件（见 [config.py](file:///d:/lingdong/Co-Sight/config/config.py)，[mcp_server_config.json](file:///d:/lingdong/Co-Sight/config/mcp_server_config.json)）。
- `app/`：核心业务代码。
  - `app/cosight/`：Agent 引擎主体（Planner、Actor、Tools、Plan/Task 管理）（见 [cosight](file:///d:/lingdong/Co-Sight/app/cosight)）。
  - `app/agent_dispatcher/`：偏 DDD 分层的“技能/实体/MCP 适配”实现（domain/application/infrastructure）（见 [agent_dispatcher](file:///d:/lingdong/Co-Sight/app/agent_dispatcher)）。
  - `app/common/`：通用日志与工具函数（见 [common](file:///d:/lingdong/Co-Sight/app/common)）。
- `cosight_server/`：Web 服务、路由、SDK、静态前端资源（见 [cosight_server](file:///d:/lingdong/Co-Sight/cosight_server)）。
  - `cosight_server/deep_research/`：FastAPI 应用与路由（见 [main.py](file:///d:/lingdong/Co-Sight/cosight_server/deep_research/main.py)）。
  - `cosight_server/web/`：静态前端页面（`/cosight/`）（见 [index.html](file:///d:/lingdong/Co-Sight/cosight_server/web/index.html)）。
  - `cosight_server/sdk/`：后端通用 SDK（配置、会话、缓存、工具函数）（见 [sdk](file:///d:/lingdong/Co-Sight/cosight_server/sdk)）。
- `tools/`：构建/打包脚本（PyInstaller spec 生成、拷贝静态资源等）（见 [build.py](file:///d:/lingdong/Co-Sight/tools/build.py)）。
- `requirements.txt`：项目依赖（FastAPI/OpenAI/MCP/Langfuse/搜索/多模态等）（见 [requirements.txt](file:///d:/lingdong/Co-Sight/requirements.txt)）。

## 典型运行形态（从“开发者视角”看）

- **单机调试**：直接运行 [CoSight.py](file:///d:/lingdong/Co-Sight/CoSight.py) 的 `__main__`，会创建工作区并执行一个示例任务（见 [CoSight.py:L197-L211](file:///d:/lingdong/Co-Sight/CoSight.py#L197-L211)）。
- **Web 服务**：运行 [main.py](file:///d:/lingdong/Co-Sight/cosight_server/deep_research/main.py)，提供：
  - 前端页面：`/cosight/`（静态资源挂载，见 [main.py:L158-L204](file:///d:/lingdong/Co-Sight/cosight_server/deep_research/main.py#L158-L204)）
  - API：`{base_api_url}/deep-research/search`（流式输出，见 [search.py](file:///d:/lingdong/Co-Sight/cosight_server/deep_research/routers/search.py)）
  - WebSocket：`/robot/wss/messages`（前端实时交互，见 [websocket_manager.py](file:///d:/lingdong/Co-Sight/cosight_server/deep_research/routers/websocket_manager.py)）
