# Co-Sight Multi-Repo Workspace

The three ZTE-AICloud Co-Sight related repositories, each evolving independently:

| Repository | What it is | Entry points |
|------------|-----------|--------------|
| [Co-Sight](Co-Sight/) | The core agent system: a Manus-like platform for report generation and applications (Python backend + frontend), deployable on-premises | [中文 README](Co-Sight/README-zh.md) · [GitHub](https://github.com/ZTE-AICloud/Co-Sight) |
| [Co-Knowledge](Co-Knowledge/) | Knowledge Studio: turns private knowledge into searchable, orchestrable, auditable AI assets, with frontend + backend + dual storage | [README](Co-Knowledge/README.en.md) · [中文](Co-Knowledge/README.md) |
| [Co-Sight Harness](Co-Sight%20Harness/) | The control structure around the model: a local-first agent host that runs Claude Code / Codex / DSH and similar runtimes under one shell | [README](Co-Sight%20Harness/README.en.md) · [中文](Co-Sight%20Harness/README.md) |

For deployment, architecture, and documentation, see each repo's own README and `docs/` directory.
