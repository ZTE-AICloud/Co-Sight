
#文件保存操作未合并导致的重复工具调用

[2026-05-12 14:43:56.159][14408][28352][WARNING][base_agent.py:532] file_saver called 2 times in step 3. Consider consolidating file saves to improve performance.
 
问题性质：非功能性问题，属于性能优化类告警。
原因分析：Agent 在生成多个版本内容时，将完整报告和精简报告分别保存为独立文件，导致同一 step 内重复调用 
 优化方案：
将完整报告和精简报告整合到同一个 Markdown 文件中，通过不同标题分区保存，避免多次调用 file_saver，提高执行效率。



#错误：在调用 search_wiki 工具时，程序通过 wikipedia.summary() 请求 Wikipedia 接口。由于接口返回了空响应或非 JSON 格式内容，第三方库在执行 r.json() 解析时触发 JSONDecodeError，导致工具调用失败。
问题性质：该问题属于外部接口响应异常导致的异常处理不完整问题，不属于核心业务逻辑错误。
修复方案：在 app/cosight/tool/search_toolkit.py 的 SearchToolkit.search_wiki() 方法中补充异常捕获逻辑，覆盖以下异常类型：
requests.exceptions.JSONDecodeError
requests.exceptions.RequestException
json.JSONDecodeError
兜底 Exception
同时保留原有正常逻辑：正常页面仍返回 Wikipedia URL + Summary，页面不存在时仍返回 PageError 提示，消歧义场景仍优先使用第一个候选项。
当 Wikipedia 返回空响应、非 JSON 响应、代理错误或网络请求异常时，search_wiki() 不再继续向上抛异常，而是返回可读的错误字符串
额外优化：将消歧义分支里的裸 except: 改为显式异常捕获并记录日志，避免静默吞掉未知错误。
