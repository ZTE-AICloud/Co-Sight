# 变异算子目录（K4 权威源）

> mutation-critic 选题的唯一依据。每个变异体必须标注条款号 + 适用信号。
> 加载策略：L2 按需 Read。critic 未读本文件前禁止设计变异（IT1）。

## 规则列表

| 条款 | 算子 | 变换 | 适用信号（代码形态） | 典型杀法 |
|------|------|------|---------------------|---------|
| OP-B1 | boundary-flip | `>=` ↔ `>`、`<` ↔ `<=` | 比较运算符紧邻数值字面量/常量 | 边界值断言（恰等于阈值） |
| OP-B2 | off-by-one | `+1`/`-1` 增减互换、`range(n)` ↔ `range(n+1)` | 索引/计数/分页计算 | 长度与边界序列断言 |
| OP-A1 | arithmetic-swap | `+` ↔ `-`、`*` ↔ `/` | 算术表达式（金额/积分/费率计算首选） | 恒等性质 + 具体值对断言 |
| OP-C1 | negate-condition | `if cond` ↔ `if not cond`、`while` ↔ 条件取反 | 分支条件（守卫、早退） | 两侧分支各一例 |
| OP-C2 | remove-guard | 删除单个 `if` 守卫（缩进提升体） | 参数校验、权限前置检查 | 非法输入必须抛错/拒绝 |
| OP-R1 | remove-call | 删除方法体内一行调用（语义改变型） | 副作用调用（累加、状态变更、日志外的写操作） | 可观察状态断言 |
| OP-K1 | constant-tweak | 数值字面量 ±1 或改符号；字符串改空串 | 魔法数、默认值、上限常量 | 阈值两侧断言 |

**组合规则**：单变异体只应用一个算子（保证击杀归因清晰）；同一行同一算子全周期只用一次（convergence-policy 强制新位置）。

## 检查清单（critic 选题）

- [ ] 每个变异点标注条款号（如 OP-B1）+ 目标行 + 变换前后语义
- [ ] 本轮 ≤8 个变异点，位置与历史轮次不重复（查 round-state.yaml 的 history）
- [ ] 优先选择"业务语义密集区"：边界、分支、算术——而非样板代码
- [ ] 对每个等价嫌疑（equivalent-suspect）做语义复核：变换是否真的改变了行为？

## 通过标准

- 变异体清单可被脚本机械执行（mutate.py 接受条款号 + 位置定位）
- 每个变异体有唯一 id：`M{round}-{seq}`（如 M2-3）
- 无"凭感觉"的变异描述——必须精确到"第 N 行，运算符 X 变为 Y"

## 等价变异处理

确认语义等价（行为不变）的变异体：不计入存活、不计入击杀，单独记录于报告的 `equivalent_mutants[]`，供人工抽查算子有效性。
