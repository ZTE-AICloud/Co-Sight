# DC-002: Skill 构建方案审批

> 触发: Skill 创建/优化 Pipeline 的方案生成后
> 协议类型: go_no_go
> 目标: 审批 Skill 构建方案后由 build-planner SubAgent 执行

## 审批流程

与 DC-001 结构相同（4 步结构化审批），但审批对象是 Skill 而非 Agent:
- Step 1: Skill 文件清单（SKILL.md + references/ + scripts/ + templates/）
- Step 2: Skill 特有的风险（格式不兼容、工具依赖、知识过时）
- Step 3: Skill 验证 spot-check（SK-S1~S11 检查项）
- Step 4: Approve / Adjust / Cancel

差别在于 Step 2 风险列表聚焦 Skill 特有的风险维度:
- Skill 格式未按 Anthropic 规范（metadata name + description）
- 引用的工具在当前环境中不可用
- 知识文件引用过时或不存在
