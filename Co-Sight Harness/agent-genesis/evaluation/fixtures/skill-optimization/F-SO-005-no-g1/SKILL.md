# Code Review Reporter

> description: 生成代码审查报告

## 流程

1. 读取 Git diff 文件
2. 逐文件分析变更内容
3. 对每个变更文件分类：安全变更、性能变更、风格变更、逻辑变更
4. 对每类变更生成审查意见
5. 自我审查：确认审查意见的准确性（检查结论是否有代码证据支撑）
6. 生成最终 Markdown 格式报告，包含：文件清单、按严重级别排序的问题列表、改进建议
7. 将报告输出到 /tmp/review-output/report.md

## 审查维度

- 安全性: SQL注入、XSS、认证绕过
- 性能: N+1查询、不必要循环、大对象分配
- 可维护性: 命名、注释完整性、函数长度
