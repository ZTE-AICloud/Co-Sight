# AgentGenesis 软校验评分细则

> 来源: evaluation/pass-criteria.md 软校验项
> 用途: 5 维度 × 5 级描述的人工评分参考

## S-01: 模式匹配准确性 (权重 30%)

| 分数 | 标准 |
|:----:|------|
| 5 | 所有选中模式精确对应需求语义意图，无冗余、无遗漏 |
| 4 | 主要模式匹配正确，个别辅助模式可商榷但不影响整体架构 |
| 3 | 关键模式正确，但存在 1-2 个不相关或遗漏的模式 |
| 2 | 模式选择有显著偏差，缺少核心模式或引入了不恰当的架构 |
| 1 | 模式选择与需求语义几乎无关 |

## S-02: Spec 内容正确性 (权重 25%)

| 分数 | 标准 |
|:----:|------|
| 5 | 填充值完全匹配用户需求，所有字段准确无误 |
| 4 | 核心字段正确，细节有少量可接受的偏差 |
| 3 | 主要框架正确但部分字段需用户介入调整 |
| 2 | 多处内容需要修正，结构正确但填充错误较多 |
| 1 | 内容与需求严重不符 |

## S-03: 审查质量 (权重 15%)

| 分数 | 标准 |
|:----:|------|
| 5 | 审查发现真实问题，无假阳性，每个发现含具体修复指导 |
| 4 | 发现有效问题，个别发现过于宽泛但方向正确 |
| 3 | 发现混合了真问题和假阳性，或缺少具体修复指导 |
| 2 | 大部分发现是假阳性，或遗漏了明显问题 |
| 1 | 审查完全无效，无有效发现或全为误报 |

## S-04: 修复方向可行性 (权重 15%)

| 分数 | 标准 |
|:----:|------|
| 5 | 诊断建议在上下文中可直接操作，步骤明确 |
| 4 | 建议方向正确，实现细节需要轻微调整 |
| 3 | 建议大致可行但缺少关键步骤 |
| 2 | 建议方向模糊，难以直接执行 |
| 1 | 诊断建议不可操作或方向错误 |

## S-05: 章节间一致性 (权重 10%)

| 分数 | 标准 |
|:----:|------|
| 5 | 跨章节引用完全闭合，无矛盾，版本/字段/路径全部一致 |
| 4 | 主要引用闭合，个别交叉引用路径需要微调 |
| 3 | 存在 1 处矛盾或不一致引用 |
| 2 | 多处矛盾，数据流与实体表不一致 |
| 1 | 章节间严重矛盾，无法形成连贯的 Spec |

## S-06: Plan 质量 (权重 —)

| 分数 | 标准 |
|:----:|------|
| 5 | Plan 清晰完整、风险识别准确、决策说明充分，构建类型/架构图/文件清单/风险缓解全部到位 |
| 4 | Plan 主体清晰，个别风险或缓解措施可补充 |
| 3 | Plan 基本可用，但缺少关键决策说明或风险分析 |
| 2 | Plan 存在显著遗漏，多个必需章节缺失 |
| 1 | Plan 不可用，无法作为构建依据 |

## S-07: 运行时质量 (权重 —)

> 由 Phase 5 evaluator-agent 打分。评分细则见 [runtime-rubric.md](runtime-rubric.md)。

| 分数 | 标准 |
|:----:|------|
| 5 | 4 维加权总分 >= 4.5，Agent 实际行为完全符合预期，输出可直接交付 |
| 4 | 加权总分 >= 4.0，主要行为正确，个别边缘情况可改进 |
| 3 | 加权总分 >= 3.5 + correctness >= 3.0 + completeness >= 3.0，基本可用但需修正 |
| 2 | 加权总分 < 3.5 或 correctness < 3.0 或 completeness < 3.0，触发 REVISE |
| 1 | Agent 崩溃/超时/无输出，不可评估 |
