# 安全规则（通用）

> This file extends common/security.md

> AgentGenesis 自研资产 — 安全底线清单，适配到目标 Agent 时按暴露面裁剪。

## 提交前强制检查

- [ ] 无硬编码密钥（API key、密码、token）— 一律环境变量或密钥管理器
- [ ] 所有用户输入在边界验证
- [ ] SQL 注入防护：参数化查询，禁止字符串拼接 SQL
- [ ] XSS 防护：动态 HTML 必须转义/净化
- [ ] 状态变更操作有 CSRF 防护
- [ ] 认证/授权路径已验证，不存在绕过
- [ ] 所有端点有速率限制
- [ ] 错误消息不泄露内部细节（堆栈、路径、密钥名）

## 密钥管理

- 源代码永不硬编码密钥；启动时校验必需密钥存在
- 疑似泄露立即轮换，并全库排查同类问题
- 日志中不出现密钥值；审计日志记录"谁、何时、用了哪个密钥ID"

## 命令执行安全

- 拼接用户输入进 shell 命令前必须转义/参数化
- 危险命令（`rm -rf`、重定向覆盖、权限变更）需要显式确认或白名单
- 文件路径操作防目录穿越：规范化后校验前缀在白名单内

## 外部数据

- 不信任任何外部数据：API 响应、用户输入、文件内容、环境变量
- 反序列化前校验来源；限制解析大小防炸弹
- 出站请求校验目标地址，防 SSRF（禁止内网地址，除非显式允许）

## 发现安全问题时的响应

1. 立即停止当前工作
2. 修复关键问题后再继续
3. 轮换所有可能暴露的密钥
4. 全库审查同类问题
