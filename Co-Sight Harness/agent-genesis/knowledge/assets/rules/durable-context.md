# 持久上下文规则

> This file extends common/durable-context.md

> AgentGenesis 自研资产 — 防上下文坍缩（Context Collapse）：长会话中 LLM 逐渐丢失早期约束、退化回通用模板。

## 核心风险

全量重写或大范围修改时，LLM 倾向回归通用模板，丢失历史积累的领域特定细节。因此：

## 硬规则

1. **增量修改**：每次修改范围 ≤2 个章节/文件；禁止整篇重写
2. **修改前留痕**：记录被改区域的当前内容（或校验和），修改后可 diff 验证无关区域未被波及
3. **追加优先**：新增条目追加到已有列表末尾，不重建表格
4. **保留原文**：修改段落时保留周围未涉及的内容逐字不动

## 何时允许大改

- 结构性缺陷（多个 CRITICAL 分散在多处）→ 回到设计阶段重匹配，而不是原地重写
- 用户显式要求重写 → 先输出 diff 预览，确认后执行

## 状态外置

- 跨步骤的中间产物落盘到 work/ 目录，不依赖对话上下文
- 长流程每步开始/结束更新状态文件，中断后从断点恢复
- 会话重启先读状态文件，不凭记忆续做

## 自检清单

- [ ] 本次修改范围 ≤2 个章节？
- [ ] 未修改区域的校验和与改前一致？
- [ ] 新增内容是追加而非重排？
- [ ] 领域特定细节（专有名词、既有约定）全部保留？
