# Brief 工序模板 — rule（L2 规则文件）

> 红线: 每条规则可由输入直接判定（K4 语义），禁止"视情况而定"式规则

## 生成工序（3 步）

1. **规则列表**: 编号条款（K4 时执行者须能引条款号），每条含判定信号（diff/输入中可见的模式）
2. **检查清单 + 通过标准**: checklist 可操作项；过什么/挂什么（量化或枚举）
3. **交叉引用**: 指向 CLAUDE.md 消费节 + 相邻规则（如 owasp→review-checklist）
   【自查】每条规则可判定? 清单与通过标准成对?

## 落点规则

`.claude/rules/{name}.md`。通用规则走 generic_copy 直复制（不参与本工序）；本模板服务定制规则。

## 自样例

同 build 中首个 rule 生成后，后续 rule 与其保持同构；已读过可跳过。
