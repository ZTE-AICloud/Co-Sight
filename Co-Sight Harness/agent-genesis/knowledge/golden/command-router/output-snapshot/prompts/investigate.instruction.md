# investigate — 调查/编码指令

识别问题类型（复现/继续/报告）后按下列步骤执行：

1. **识别问题类型**：Repro（构造最小复现）/ Continue（接续既有调查）/ Report（汇总现状）。
2. **构造测试用例**：为复现问题写最小化测试输入。
3. **确认问题可复现**：在受控环境重跑，记录实际行为。
4. **提出解决方案**：每个候选方案独立描述，含修改范围。
5. **验证方案**：逐个测试，标记 CONFIRMED / DENIED，不通过的方案记录失败原因。
6. **代码审查 + 保持修改**：通过后做最终审查，保留已验证的修改，移除实验残留。

每步产出落盘为独立文件（`01-repro.md` / `02-cases.md` / ...），支持断点恢复。
