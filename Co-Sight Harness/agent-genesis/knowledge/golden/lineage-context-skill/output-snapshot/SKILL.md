# lineage-context-skill — 可溯源语义上下文管线

## 职责

对指定代码库构建可检索的语义上下文索引, 并在查询时返回**带完整 lineage
注记**的代码块——每块可回溯到 `相对路径:行区间`, 绝不返回无出处的内容。

## 前置契约（用户自备凭据, 启动校验, 缺项即拒）

管线两段外部依赖, 全部由用户环境变量提供（模板见 `templates/env.example`）:

1. **嵌入服务**: `EMBEDDING_PROVIDER` + `EMBEDDING_MODEL` + 对应服务商的
   API key（多服务商选一, 注释掉未选段）。
2. **向量库端点**: `VECTOR_DB_ADDRESS` + `VECTOR_DB_TOKEN`。

**启动校验清单（fail-closed, 缺一不可）**:

- [ ] 两个段的所有必需环境变量已设置且非占位值（`your-...-here` 视为未设）
- [ ] 向量库端点可连通（一次空查询探活）
- [ ] 嵌入模型可用（单条探针文本试嵌入, 校验维度一致）

任一不过 → 停止并列出缺项清单, **绝不部分执行**。

## 管线五段

1. **切分**: 按 AST 优先、纯文本兜底切分为语义块; 每块即刻标注
   `{relativePath, startLine, endLine, language}`——lineage 在切分点生成,
   后续各段只透传不补写。
2. **嵌入**: 批量嵌入（默认批 100, 按服务商吞吐可调）; 嵌入向量与 lineage
   元数据同批绑定, 不落孤儿向量。
3. **入向量库**: 块向量 + lineage 元数据 + 内容原文一并 upsert;
   集合级 Merkle 指纹记库, 作为增量同步基线。
4. **检索**: 查询经同一嵌入模型转向量; 支持纯向量或 向量+BM25 混合模式;
   每结果强制五元组 `{content, relativePath, startLine, endLine, score}`,
   language 随元数据带出。
5. **组装**: 按分值取 top-N 块注入上下文; 每块引用格式
   `[路径:行区间]` 前缀, 缺 lineage 前缀的块禁入最终上下文。

## 增量同步

- 同步时按文件 Merkle 指纹对账: 仅变化文件重切分重嵌入, 未变化文件零触碰。
- 删除检测: 指纹缺失即删库内对应块（含向量+元数据+原文三件套）。

## 不变量（lineage 纪律）

- 任何面向用户的检索结果必须 100% 携带 lineage 五元组, 一块不缺。
- lineage 只在切分段生成一次, 后续段禁改写行区间。
- 凭据只读环境变量, 禁写入任何产物文件、禁入日志。

## 反模式

- 返回无出处内容块 / 行区间与原文不符
- 凭据硬编码或写入索引产物
- 缺环境变量时降级跑通（必须 fail-closed）
- 全库重嵌入式同步（未走 Merkle 增量）
