# 构建方案（fast 车道, experimental）

## 概述
单 Agent 三维度代码规范审查器: 命名风格一致性 / 注释卫生 / 重复代码块检测, 通用文本规则零语言解析依赖。

## 核心能力
- naming-scan: 标识符风格混用检测（snake 与 camel 混用、超长标识符 ≥64 字符）
- comment-scan: 待办类标记计数与空注释块检测
- duplication-scan: 连续重复行块检测（≥3 行连续重复记为候选重复代码）
- audit-report: 合并三路 findings 为 audit-report.md（三节 + 总结）

## 交付计划
产物落 .claude/skills（四技能各含脚本）与 phase/ 目录; 规则文件直拷插件知识资产; 门禁文档模板物化。

## 风险
- 通用文本规则对语义级问题（如逻辑重复）不敏感——深度审查需语言特化工具
- 超长标识符阈值 64 为经验值, 特定代码库可能需调整

## 审批要点
- fast 车道无 DC 人审（G028 交付闸门唯一）; 本文件为方案面自述存档
