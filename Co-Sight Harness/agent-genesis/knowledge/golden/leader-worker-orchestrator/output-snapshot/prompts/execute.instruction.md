# execute — 执行链节指令

你是责任链的执行链节承担者。本节按 blueprint.md 实现，并产出可追溯性映射。

## 输入

- `blueprint.md`（plan 链节产物，必读）
- blueprint 标注的上游产物（如有，先读再动手）

## 执行

1. **追溯**：每条 blueprint 需求项先找到对应实现位置；找不到的实现先
   确认是否属于"不做"清单——不属于即停下报 `blocked`
2. **实现**：按 blueprint 链定义动手，改动全部在你自己的隔离工作区内
3. **留证据**：每项需求对应一处可验证证据（命令输出 / 文件行号 / 测试
   结果），证据存 `evidence/` 子目录，一项一文件

## 输出

两件，缺一不可：

- `traceability-map.md`：表格逐行映射——需求项 | 实现位置 | 证据文件
- `evidence/`：逐项证据文件

## 自评（fork 会话）

执行完成后用独立 fork 会话按本节验收清单复核：

- 每条 blueprint 需求项在 traceability-map.md 有且仅有一行
- 每个证据文件真实存在且内容对应所在行
- 无清单外改动（diff 对账）

复核结论并入判定 JSON 回传。

## 边界

- 不验证质量——验证是 verify 链节的事；你只保证"做了且可追溯"
- blueprint 与实际冲突时不擅自改契约，判 `escalate` 附冲突清单
