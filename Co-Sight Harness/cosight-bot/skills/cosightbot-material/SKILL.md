# cosightbot-material —— 资料处理与索引构建

## When to Activate

- 用户说"绑定 xx 为资料目录 / 工作目录"
- 用户说"把 xx 文件/目录加入知识库"（等价上传；默认进**当前会话**知识库，用户明确说"全局/智能体知识库"才用 `--global`）
- 用户说"把 xx 从知识库删除"
- 用户说"资料有更新 / 同步一下 / 重建索引"
- 用户问"知识库状态 / 有哪些资料"

## 执行入口

```bash
python "${CLAUDE_PLUGIN_ROOT}"/skills/cosightbot-material/scripts/material_cli.py <子命令>
```

| 子命令 | 用法 | 说明 |
|---|---|---|
| `bind <目录>` | 绑定资料目录 | 成功后**自动首次构建** |
| `status` | 状态查询 | 绑定/索引状态 + "N 个文件变更待入库"对账 |
| `build [--force]` | 手动构建 | 默认指纹增量（无变更秒退）；`--force` 全量。仅用于**外部直接改动**绑定目录后的刷新 |
| `list` | 列出资料 | 绑定目录 + 会话级上传 + agent 级收件箱 |
| `unbind` | 解除绑定 | 清理该路由的索引数据 |
| `ingest [--global] <路径...>` | 加入知识库 | 默认进当前会话路由（等价聊天上传）；成功后**自动增量构建** |
| `remove [--global] <文件名...>` | 删除文件 | 从对应路由删除，**自动增量删 nodes** |

## 环境自检（preflight）

脚本返回 **exit 3** + `{"hint": "please_run_install", ...}` 时：运行环境未初始化或依赖已变更——执行 `python "${CLAUDE_PLUGIN_ROOT}"/scripts/install.py`（幂等、非交互），装完按 `数据根目录下的 .env` 模板引导用户配置环境变量（**构建必需 LLM**：`OPENAI_*` 优先，未配则回退继承 CC 会话的 `ANTHROPIC_*`；embedding 已不需要——去向量构建）。**不得绕过**（S-05）。

## 构建的执行方式（重要）

- **操作即构建**：bind/ingest/remove 成功后脚本已自动触发增量构建，无需再喊 build；unbind 直接清除该路由的索引目录（等效于全量删除，不走增量）。
- **秒级增量**（日常）：前台执行，完成后向用户汇报摘要（"构建完成：新增 X 篇，跳过 Y 篇"）。
- **分钟级首次构建/大目录**：**一律后台执行**（Bash run_in_background）——启动后立即告知用户"已开始构建，完成后我会汇报"；用户中途问进度时读取后台任务输出文件尾部回答；命令退出后汇报最终摘要。
- 进度行为 `[progress] ...`（stdout），按行输出。

## 会话级知识库

- ingest 默认进当前会话路由 `数据根/workspace-main/llamaindex_数据根/upload_files/<session_hash>/`，仅当前会话可检索；用户说"全局/智能体知识库"时用 `--global` 进 `inbox/`。
- 会话标识来自 CC 自动注入的 `CLAUDE_CODE_SESSION_ID`；老版本 CC 未注入时脚本自动降级 agent 级并输出 notice，按 notice 如实告知用户。

## 进度汇报话术

1. 「开始绑定目录，正在首次构建（大目录可能需要几分钟）」
2. 「已开始构建，完成后我会汇报」（后台执行时）
3. 「构建完成：新增 X 篇，跳过 Y 篇」
4. 「已删除 X 个文件并更新索引」

## Not for

- 不做知识检索问答（那是 cosightbot-retrieve，纯只读）
- 不监听目录实时变化（绑定目录被外部直接改动时，引导用户说"资料有更新"→ build； status 会显示待入库变更数）
- 不处理 SOC 标书知识库（由本插件的标书智能体 soc-expert / cosightbot-soc-* 承担）

## 检查清单

- [ ] 资料操作完成后索引已自动更新（auto_build=true）
