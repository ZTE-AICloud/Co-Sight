# 智能体技能（装配）

> 状态：**已定稿并实现**（2026-10-26）。技能装配 = 把来源技能**整拷**进智能体当前产物的
> `.claude/skills/<目录名>/`，复制完即生效。**不落库、不写 manifest、不改 `CLAUDE.md`**；
> 重建出的新 `vN` 不会自动带上旧技能（用户重新装配）。
> 代码落点：`server/src/modules/agent/agent-skill.service.ts`、`server/src/shared/skills/skill-md.ts`。

## 1. 端点总表

| 方法 | 路径 | 请求 | 成功响应 |
|---|---|---|---|
| GET | `/agents/{agentId}/skills` | — | `200` `{ agentId, ready, reasons, product, items }` |
| POST | `/agents/{agentId}/skills` | `{ path, version? }` | `200` `{ item, product }` |
| POST | `/agents/{agentId}/skills/remove` | `{ name }` | `200` `{ removed }` |

资源身份一律进路径（与 `agents/*` 同一套规则），请求体只带可变字段。

## 2. 落点与时序

```
来源（技能库或智能体产出的技能）
  {skillsRoot}/output/skills/<name>/<vN>/          ← 整拷内容，剥掉 vN 层
        │
        ▼
目标智能体当前产物
  <agentRoot>/development/output/agents/<agentName>/<latest vN>/.claude/skills/<name>/
```

- **目标目录由服务端解析**：`locateProducedAgent(<development>)` 返回 `{ agentName, version, dir }`，
  **不拼死 `v1`** —— 重建后会是最新的 `vN`。
- **复制完即生效**：runtime 原地读产物；preview / evaluation 每次起 run 前从产物整拷（物化），
  自动带上这一批。开发阶段（构建工作台）不读产物的 `.claude/skills`，不受影响。
- **来源版本**：`version` 缺省取来源目录内数字最大的 `vN`；来源没有版本子目录时整目录拷贝。
  显式传 `version` 时只接受 `v^[0-9]+$` 且目录必须存在。
- **只复制内容**：`<name>/<vN>/SKILL.md` → `<name>/SKILL.md`；引擎的发现要求 `SKILL.md` 在技能目录根部。

## 3. 前置门禁

写操作（装配 / 删除）的检查顺序：

| # | 检查 | 失败 |
|---|---|---|
| 1 | `path` 形态、来源存在、含 `SKILL.md`（仅装配） | `400` / `404` |
| 2 | 智能体存在、`source=user` | `404` / `409`（内置只读） |
| 3 | 该智能体**四个阶段**都没有活跃 run | `409` |
| 4 | 产物 `completed`（流程收尾 + 交付门禁 PASS/CONCERNS） | `409` |
| 5 | 同名（目录名或 frontmatter name） | `409` |
| 6 | 复制（`errorOnExist` 兜住并发） | `409` |

400 / 404 / 409 都**不产生半成品**：复制是最后一步。

`GET` 是只读：未就绪也是 `200`，用 `ready=false` + `reasons` 表达（与 4.10 同口径）；
内置智能体同样 `409`（定义目录随产品分发，不参与装配）。

## 4. 请求与响应

装配：

```http
POST /api/smart-factory/v1/agents/agt_xxx/skills
{ "path": "/home/u/.cosight-harness/smart-factory/skill-workshop/output/skills/report-gen", "version": "v3" }
```

```json
{
  "item": {
    "name": "report-gen",
    "displayName": "report-gen",
    "description": "把零散的周报素材整理成固定格式",
    "version": "1.0",
    "path": "/…/agents/agt_xxx/development/output/agents/weather/v3/.claude/skills/report-gen",
    "updatedAt": "2026-10-26T06:00:00.000Z"
  },
  "product": {
    "agentName": "weather",
    "version": "v3",
    "dir": "/…/output/agents/weather/v3"
  }
}
```

清单：

```json
{
  "agentId": "agt_xxx",
  "ready": true,
  "reasons": [],
  "product": { "agentName": "weather", "version": "v3", "dir": "/…" },
  "items": [
    {
      "name": "weather-query",
      "displayName": "weather-query",
      "description": "城市天气查询",
      "version": "1.0",
      "path": "/…/.claude/skills/weather-query",
      "updatedAt": "2026-10-26T06:00:00.000Z"
    }
  ]
}
```

字段：

| 字段 | 说明 |
|---|---|
| `name` | 产物里的**目录名**，也是 `/` 命令名；删除时用它 |
| `displayName` | `SKILL.md` frontmatter 的 `name`；缺失时等于 `name` |
| `version` | frontmatter 的 `version`（如 `1.0`）；没有则空串 |
| `path` | 产物里的技能目录绝对路径（优化时拼 `<path>/SKILL.md`） |
| `ready` / `reasons` | 产物是否就绪及原因（仅 `GET`） |
| `product` | 目标产物；未就绪为 `null` |

## 5. 语义

- **不记来源**：清单里的项就是产物目录下的子目录；构建生成的与装配进来的完全同构。
- **不钉版、不同步**：复制完与来源无关联；来源后续更新不影响已装配的一份。
- **重建不自动带过去**：新 `vN` 是干净重写，装配的技能需要重新装。
- **删除**：移除产物里的技能目录；不存在返回 `404`，不幂等。
- **改名 / frontmatter 名冲突**：目录名与 frontmatter name 任一与已有技能相同都算冲突（409）。
- **内置智能体**：`GET` / 装配 / 删除一律 `409`（`error.conflict.builtin_agent`）。

## 6. 前端落点

- 技能库卡片「装配」→ 选目标智能体 → 装配（`AssembleDialog`）。
- 设计页生成阶段「产物技能」→ 清单 / 优化（命令放回发送框）/ 删除（`ProductSkillsDialog`）。
- 预览阶段 `/` 词表 = 本端点 `GET` 的 `items`（`/＜name＞`），不再用首页那份产品预设。
  若要同时列斜杠命令，改用详情的 `skills` / `commands`（[4.14](./4.14-可执行技能与命令.md)），
  并在进入预览时重拉该详情。
