# 网络优化评估

本技能用于网优场景下，在完成根因定位后，对拟采取的优化方案进行评估，并预测效果与风险。

## 使用场景

- 对参数调整、天线调整、扩容、迁站等方案做可行性评估
- 结合历史数据或仿真评估预期效果
- 识别方案风险与回退条件
- 输出评估结论与实施优先级建议

## 评估维度

- **效果预期**：KPI 改善幅度、覆盖/容量提升预估
- **实施成本**：改造成本、实施难度、周期
- **风险与回退**：对现网的影响、回退方案

## 脚本执行

本技能通过执行 `scripts/skill.py` 中的 Python 脚本获取评估结果。调用方式：

```bash
cd skills/network-optimization-assessment
python scripts/skill.py
```

或在 Python 中导入：

```python
from scripts.skill import get_content
result = get_content()  # 返回评估结论字符串
```

`get_content()` 返回当前技能的评估输出内容。

## 说明

与「网络根因定位」配合使用：在完成根因定位后，使用本技能对优化方案进行评估与排序。
