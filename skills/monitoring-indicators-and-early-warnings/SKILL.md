# 监控指标与早期预警

本技能用于在故障排障场景下，对系统或网络的监控指标进行持续关注与解读，并识别早期预警信号。

## 使用场景

- 查看并解读 KPI、流量、时延、丢包率等关键监控指标
- 识别指标趋势异常、阈值越界或突变
- 结合基线或历史数据判断是否出现早期预警
- 为后续「告警根因诊断」提供指标依据

## 常见指标类型

- **性能指标**：时延、吞吐、成功率、响应时间
- **资源指标**：CPU、内存、磁盘、连接数
- **业务指标**：请求量、错误率、超时率

## 脚本执行

本技能通过执行 `scripts/skill.py` 中的 Python 脚本获取监控与预警结果。调用方式：

```bash
cd skills/monitoring-indicators-and-early-warnings
python scripts/skill.py
```

或在 Python 中导入：

```python
from scripts.skill import get_content
result = get_content()  # 返回监控与预警输出内容
```

`get_content()` 返回当前技能的监控与预警结果。

## 说明

与「告警根因诊断」配合使用：先通过本技能发现异常与预警，再使用根因诊断技能分析告警原因。
