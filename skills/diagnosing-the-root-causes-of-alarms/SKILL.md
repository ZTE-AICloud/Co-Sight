# 告警根因诊断

本技能用于在故障排障场景下，对已产生的告警进行根因分析，定位告警来源并推断可能原因。

## 使用场景

- 根据告警内容、监控指标与拓扑信息分析根因
- 区分根因告警与衍生告警，避免重复处理
- 结合「监控指标与早期预警」中的异常指标做关联分析
- 输出可能原因列表及处理建议

## 分析思路

- **关联分析**：告警与指标、配置变更、容量等关联
- **时序分析**：告警与指标的时间先后与传播关系
- **拓扑分析**：从受影响节点反推根因节点或链路

## 脚本执行

本技能通过执行 `scripts/skill.py` 中的 Python 脚本获取根因诊断结果。调用方式：

```bash
cd skills/diagnosing-the-root-causes-of-alarms
python scripts/skill.py
```

或在 Python 中导入：

```python
from scripts.skill import get_content
result = get_content()  # 返回根因诊断输出内容
```

`get_content()` 返回当前技能的根因诊断结果。

## 说明

与「监控指标与早期预警」配合使用：在发现异常与预警后，使用本技能进行告警根因诊断。
