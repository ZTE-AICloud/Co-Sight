# 网络根因定位

本技能用于网优场景下，对网络质量劣化或故障进行根因定位，缩小问题范围并给出定位结论。

## 使用场景

- 容量、覆盖、干扰、切换等问题的根因定位
- 结合 MR/CDT、告警、KPI 等数据判断问题点
- 区分设备侧、参数侧、规划侧等原因
- 输出根因定位结论与证据摘要

## 常见问题类型

- **容量问题**：拥塞、资源不足、扩容需求
- **覆盖问题**：弱覆盖、过覆盖、空洞
- **干扰问题**：同频/邻频干扰、外部干扰
- **切换问题**：切换失败、乒乓切换、邻区关系

## 脚本执行

本技能通过执行 `scripts/skill.py` 中的 Python 脚本获取根因定位结果。调用方式：

```bash
cd skills/network-root-cause-localization
python scripts/skill.py
```

或在 Python 中导入：

```python
from scripts.skill import get_content
result = get_content()  # 返回根因定位输出内容
```

`get_content()` 返回当前技能的根因定位结果。

## 说明

与「网络优化评估」配合使用：先通过本技能完成根因定位，再使用优化评估技能制定方案与评估效果。
